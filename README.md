# TMU Velocity Robotics Labs

My lab work from TMU's Velocity Autonomous Robotics team, using ROS 2 and the F1TENTH simulator.

## Labs

**Lab 2 — Automatic Emergency Braking**
- Implemented LiDAR-based collision detection and emergency braking.

**Lab 3 — Wall Following**
- Built a PID controller to follow walls using LiDAR data.
- Added doorway detection and speed adjustments.
- Successfully completed laps around the Levine track.

## Tech Stack

Python, C++, ROS 2, Docker, RViz, F1TENTH
